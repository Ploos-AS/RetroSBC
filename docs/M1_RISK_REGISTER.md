# M1 Risk Register

| Risk | Impact | M1 treatment |
|---|---|---|
| B1 small-volume availability | Critical | procurement gate before schematic freeze |
| B1 lifecycle/documentation | High | require current design package and lifecycle evidence |
| PCIe combo-resource conflict | High | SPI fallback; validate lane mux in M2 |
| ECP5UM availability | High | retain package/speed-grade flexibility |
| FPGA RAM bandwidth/capacity | High | dedicated >=32 MiB SDRAM baseline |
| 5 V retro interfaces | High | mandatory translation/protection |
| FPGA PCIe complexity | Medium/High | not required for first boot |
| Thermal load | Medium | thermal/fan provisions required |
| Connector density | Medium | no Pi-size requirement |
| BOM single-source parts | Medium | apply Ploos-AS component policy |
| Proprietary ROM/OS assets | Medium | external assets only |
| FPGA core licensing | Medium | provenance/license review per imported core |
